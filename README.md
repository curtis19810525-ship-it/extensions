# NBA 回家日常（只串現有爬蟲）

把 `nba_home.py` 和 `回家日常.bat` 放到本機「抓取NBA網路資料」，與 `run_all.py` 同一層。雙擊 bat 即可。

賽果日跑步驟 1～3，日期會傳進現有的爬蟲與兩支批次轉換。關注日跑步驟 4～6；這三步若本來不吃日期，命令列不附加日期。某一支失敗仍繼續，最後列出結果。

不改 Excel 版面，不歸檔，不填盤口，不匯出記事本。手動選單仍用 `爬蟲正負各隊.bat`。

同資料夾的 `run_all.py` 若是 MLB 選單，這支會直接停止。沒有 `run_all.py` 時，步驟 6 呼叫 `nba_lineups.py`。

先關 `NBA26-27爬蟲數據.xlsx` 再執行。日期用「每日數據」的開賽日。

```bat
python nba_home.py --dry-run 20261021 20261022
```
